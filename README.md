# MathLearnSolve — Math Learn Solve

MathLearnSolve is a free Windows math-learning app for Moroccan high-school students. Learn with structured lessons and exercises, and use the built-in function analyzer to study and graph functions.

- **Website:** <https://miriben.github.io/MathLearnSolvee/>
- **Download the latest Windows installer:** <https://github.com/miriben/MathLearnSolvee/releases/latest/download/MathLearnSolve-Setup.exe>
- **Release notes and optional OCR downloads:** <https://github.com/miriben/MathLearnSolvee/releases/latest>

## Trial version

The five-day trial includes the first two courses and their exercises, plus three successful function analyses.

The main app works offline after installation. OCR is optional and needs an internet connection on first use to download its models.

## Version française

MathLearnSolve est une application gratuite pour Windows destinée aux élèves marocains du lycée. Elle propose des cours et des exercices de mathématiques ainsi qu'un outil d'analyse et de tracé de fonctions.

- **Site officiel :** <https://miriben.github.io/MathLearnSolvee/>
- **Télécharger la dernière version Windows :** <https://github.com/miriben/MathLearnSolvee/releases/latest/download/MathLearnSolve-Setup.exe>
- **Notes de version et téléchargement facultatif de l'OCR :** <https://github.com/miriben/MathLearnSolvee/releases/latest>

### Version d'essai

L'essai dure cinq jours et donne accès aux deux premiers cours et à leurs exercices, ainsi qu'à trois analyses de fonctions réussies.

L'application principale fonctionne hors ligne après installation. L'OCR est facultatif et nécessite une connexion Internet lors de sa première utilisation pour télécharger ses modèles.

Ce dépôt public héberge le site et les installateurs, pas le code source de l'application. La marque du produit est **MathLearnSolve**; le dépôt s'appelle **MathLearnSolvee**.
